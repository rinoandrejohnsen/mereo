parent_start:
{
    child_start:
    {
        grandchild_start:
        {
             goto parent_end; // OK: jumps outward
        }
        grandchild_end:
    }
    child_end:
}
parent_end:


## notes

code inside deeper scopes can safely jump to any ancestor’s scope_start or scope_end, but not into unrelated deeper/sibling scopes.
